# GODANローマ字入力の監査記録

対象は GODAN（画像配置）・GODAN（ヒント付き）・GODAN（幅比較）と、4タブセット内のGODANです。

## 基準

- azooKeyの標準ローマ字表から、最後が母音で、その前が子音だけのかな綴り265通りを採用。
- Mozcだけにある同条件の19通りを追加。合計284通り。
- 既存の五段との互換性のため、quは「くぅ」、xka/lkaは「ゕ」、xke/lkeは「ゖ」。この5綴りはMozcの「く・ヵ・ヶ」と異なります。
- 五段独自の子音1文字＋右フリックを保持。複数子音＋右フリックは明示した綴りの音に対応。
- n/n'のような未確定状態や記号ショートカットは284通りに含めません。nn・xn・tch・促音は別の回帰テストで検査します。nnは従来どおり2入力を消費します。

出典は [azooKey標準表](https://github.com/azooKey/AzooKeyKanaKanjiConverter/blob/93766c46e31fa6a18b7ced49dab31337780f6f45/Sources/KanaKanjiConverterModule/InputManagement/InputTables/defaultRoman2Kana.swift) と [Mozc標準表](https://github.com/google/mozc/blob/60af02ff797275f2ba1b7fddccdec916798d112e/src/data/preedit/romanji-hiragana.tsv)。参照データは [data/romaji-kana.json](../data/romaji-kana.json) に固定しています。

## 検査方法と範囲

- 配布JSONの実際のinputとreplace_last_charactersを順番に実行し、最長の一致する末尾を置換。
- 標準284綴りと既存別表記2通りの通常入力・左（っ）・上（ん）、子音2文字以上の右フリック。
- かな・漢字を前後に置いた入力、子音重複の促音、nの後の子音、xnとtch、五段の既存ショートカット。
- 286×286＝81,796組の連続入力を、3配列とセット内GODANそれぞれで照合。
- 既存のwh入力などの重点テストも維持。
- 配置・アクション・切替先・セットの一致、共通表との同期、17枚の図の再生成を確認。

実行コマンド：

~~~sh
python -m unittest discover -s tests -v
python scripts/check_layouts.py
python scripts/update_godan_romanization.py --check
python scripts/render_previews.py
git diff --exit-code
~~~

これは直接入力と置換のモデルを使う静的な検査です。iPhone/iPadの読み込み、タッチ認識、ライブ変換、候補の確定、アプリごとの入力欄は検査していません。
